# South Hyderabad Properties website

## Overview

Build a polished, responsive real-estate website using the supplied content and Yaha Properties as a visual reference. The result will use an original blue-and-orange design, animated property storytelling, vertical property media, and strong enquiry paths.

## Pages and navigation

- Add a sticky shared header with the company mark, Home, About Us, Projects dropdown, Blog, Contact Us, and a call button.
- Build separate pages for Home, About Us, Autumn Villas, Blog, and Contact Us.
- Add a shared footer with the supplied phone, email, quick links, and social links.
- Add unique search and social-sharing descriptions for every page.

## Home page

- Create an animated first view inspired by the reference: airy white space, blue/orange type reveals, moving location/property details, and original architectural imagery.
- Add property search controls for category and location.
- Add a horizontally browsable featured-property showcase with 9:16 media.
- Introduce expertise across open plots, land development, and luxury homes in Shamshabad and Maheshwaram.

## About, project, blog, and contact

- Present the company mission, values, and Shaik Abdul Basha’s leadership and digital strategy.
- Build a focused Autumn Luxury Villas page with every supplied project fact, amenity icons, 9:16 media, brochure action, and enquiry action.
- Build a responsive editorial grid with sample articles covering market trends, investment guidance, and regional growth.
- Build a contact page with the supplied contact details, a complete enquiry form, social links, and a clearly labelled map preview.

## Visual system and interaction

- Use a crisp white foundation, strong cobalt blue, vivid orange accents, deep navy text, and restrained pale-blue surfaces.
- Use a confident geometric display face with a highly readable body face.
- Create original, cohesive property imagery for the homepage, Autumn Villas, and article/media cards.
- Add smooth entrance reveals, a rotating/sliding property presentation, subtle marquee motion, and reduced-motion support.
- Keep controls compact, corners modest, and layouts stable across mobile and desktop.

## Technical details

- Use shared React components for navigation, footer, page headings, property cards, calls to action, and vertical media.
- Use the existing carousel package and CSS animations for lightweight motion; add no backend because the brief only requests the presentation and form interface.
- Use accessible labels, keyboard navigation, proper heading order, meaningful image descriptions, and local-search-focused metadata.
- Verify key links, dropdowns, slider controls, mobile menu, form interaction, responsive views, and the final preview.
